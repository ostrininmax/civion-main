# i18n Guide

## Overview

Internationalization is implemented with a lightweight custom layer:

- Core dictionary and helpers: `apps/web/src/lib/i18n/index.ts`
- React language provider + hook: `apps/web/src/lib/i18n/context.tsx`
- Provider mounting: `apps/web/src/components/AppProviders.tsx` and `apps/web/src/app/layout.tsx`

Supported locales:

- `en` (default)
- `el`
- `ru`
- `uk`
- `hi`
- `ar`

Language selector behavior:

- The selector UI is always in English by design.
- Label is always `Language`.
- Options are always `English / Greek / Russian / Ukrainian / Hindi / Arabic`.
- This is intentional so users can always switch back.

Language is persisted in:

- `localStorage` key: `cyprus-services.locale`
- Demo state store locale field (`cyprus-services.demo-state.v4`)

## How To Add A New Translation Key

1. Add the key to `extraEn` in `/Users/maksym/Downloads/civion-main/apps/web/src/lib/i18n/index.ts`.
2. Add translated value to locale dictionaries (`extraEl`, `extraRu`, `extraUk`, `extraHi`, `extraAr`) or regenerate auto locale overlays in `/Users/maksym/Downloads/civion-main/apps/web/src/lib/i18n/generated/`.
3. Use it in UI via:
   - `const { t } = useTranslation(); t("your.key")`, or
   - `t(locale, "your.key")` / `ti(locale, "your.key", params)` if locale is passed manually.

## How To Add A New Language

1. Extend `LocaleCode` in `apps/web/src/lib/models/types.ts`.
2. Add locale code to:
   - `SUPPORTED_LOCALES`
   - `LOCALE_INTL`
   - `localeLabel` map
3. Add new dictionary object in `apps/web/src/lib/i18n/index.ts` and provide an auto-translation overlay file under `apps/web/src/lib/i18n/generated/`.
4. Add language option in `apps/web/src/components/LanguageSwitcher.tsx` (in English label format).
5. If RTL language, add locale to `RTL_LOCALES`.

## Missing Translation Fallback

- If key is missing for active locale, i18n falls back to English.
- In development, missing keys emit `console.warn`.

## RTL Handling

- Direction is set in `LanguageProvider` by updating:
  - `document.documentElement.dir`
  - `document.body.dir`
- Arabic (`ar`) is RTL, all others are LTR.
- RTL-specific layout adjustments are implemented in `apps/web/src/app/globals.css`, including:
  - Sidebar and main area flip
  - Drawer opening side flip
  - Topbar notification alignment and badge position
  - Directional arrows/breadcrumb separators

## Developer Checklist

- Find untranslated UI keys usage:
```bash
rg -n "t\\(|ti\\(|tt\\(" apps/web/src
```

- Find direct hardcoded strings in app/components:
```bash
rg -n "\"[A-Za-z][^\"]*\"|'[A-Za-z][^']*'" apps/web/src/components apps/web/src/app
```

- Validate missing keys against dictionary:
```bash
node scripts/check-i18n-keys.mjs
```
